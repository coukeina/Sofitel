README (FR)
Présentation du projet

Ce projet consiste en la conception et le développement d’un site web immersif pour un hôtel resort situé à Agadir. L’objectif est de proposer une expérience utilisateur moderne et interactive, inspirée des galeries digitales, tout en intégrant des fonctionnalités dynamiques telles que la consultation des chambres et la réservation en ligne.

Objectifs
Concevoir une interface utilisateur élégante et immersive
Mettre en valeur l’environnement et l’ambiance d’Agadir
Permettre la réservation de chambres via un système dynamique
Développer une architecture claire séparant le frontend et le backend
Fonctionnalités principales
Page d’accueil immersive avec contenu visuel (images / vidéo)
Navigation fluide entre les différentes sections
Galerie d’expériences mettant en avant les paysages et activités
Affichage des chambres avec informations (prix, description, images)
Formulaire de réservation
Technologies utilisées
Frontend : HTML, CSS, JavaScript
Backend (prévu) : Node.js / Express
Base de données (prévue) : MySQL
Structure du projet
frontend/ : interface utilisateur (pages, styles, scripts, assets)
backend/ : logique métier et API (en cours de développement)
database/ : schéma de la base de données
État d’avancement

Le projet est actuellement en phase de développement du frontend, avec une attention particulière portée à l’expérience utilisateur et au design immersif. Les fonctionnalités backend seront intégrées dans les prochaines étapes.

📄 README (EN)
Project Overview

This project focuses on the design and development of an immersive website for a resort hotel located in Agadir. The goal is to provide a modern and interactive user experience inspired by digital gallery platforms, while integrating dynamic features such as room browsing and online booking.

Objectives
Design an elegant and immersive user interface
Highlight the environment and atmosphere of Agadir
Enable room booking through a dynamic system
Develop a clear architecture separating frontend and backend
Main Features
Immersive homepage with visual content (images / video)
Smooth navigation between sections
Experience gallery showcasing landscapes and activities
Room display with details (price, description, images)
Booking form
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend (planned): Node.js / Express
Database (planned): MySQL
Project Structure
frontend/: user interface (pages, styles, scripts, assets)
backend/: business logic and API (under development)
database/: database schema
Project Status

The project is currently in the frontend development phase, with a strong focus on user experience and immersive design. Backend functionalities will be implemented in the next stages.
